读法与边界

取并集，不取交集

一个用户拥有多个角色时，权限为各角色权限之和，任一角色授予即可访问。

只读不是「禁用」

没有写权限时，前端不渲染按钮，后端同时拒绝请求。两者缺一不可。

超级管理员是例外

内置账号不依赖角色授权，避免角色被误删后系统失去管理入口。
