权限如何生效

  1. 接口声明所需权限码，如 user:create。
  2. 用户所属角色的权限取并集。
  3. 并集包含该权限码才放行，否则返回 403。
  4. 超级管理员跳过以上判断。

角色约束

  • 内置 admin 角色不可删除、不可清空权限。
  • 删除角色前需先解除其与用户的关联。
  • 删除权限前需确认引用该权限的角色范围。

创建角色

编码创建后不可修改，建议与业务语义一致，如 content_reviewer。
