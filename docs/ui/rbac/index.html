把权限做成看得见的东西。

这套原型为 PROJECT_SPEC_V2 的 RBAC 授权需求而做。核心不是多画几个页面，而是让「当前身份被允许做什么」在界面上随时可核对：菜单会少、按钮会消失、矩阵会变。
